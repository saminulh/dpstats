# About the corpus

## What the corpus is

We obtained all of the problem instances in this benchmark from public replication packages from sources such as [Harvard Dataverse](https://dataverse.harvard.edu/), [openICPSR](https://www.openicpsr.org/), and [Mendeley](https://data.mendeley.com/). To maximize relevance to privacy-sensitive contexts, we selected on statistical tasks where the samples correspond to individual people or households. The collected instances are split into a [publicly distributed set](https://huggingface.co/datasets/dpstatsbench/distribution) anyone can use for developing algorithms and a withheld set we use for official ranking.

## Licences

Every study and problem instance we redistribute in the publicly distributed set is licensed to allow redistribution. Every study's page in [Corpus](index.md) contains that study's licensing details as well as links to relevant license text. The downloadable release also carries an attribution file (`benchmark-info/attribution.json`) and the licence texts some sources require (`benchmark-info/licenses/`). The release itself is licensed under CC BY 4.0. We do not redistribute the original papers or replication packages, but each study's [Corpus](index.md) page contains links to both.

## Reporting a data problem

If you find an error in how we handle some data (e.g., licensing issues, misrepresenting a claim in the paper, or an error in a published problem instance), then please reach out to us via the [Contact](../contact/index.md) page.
