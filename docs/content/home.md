This
is a benchmarking platform for comparing differentially private algorithms on statistical estimation problems from real studies and datasets.

* Go to the [Leaderboard] page for a statistical estimation task to see how well the best private algorithms do. For a more detailed view, visit the task's [Explore] page.
* [Follow the user guide](library/index.md) to install the benchmark and run an algorithm.
* [Explore the corpus](corpus/) page to see the studies that are the source for the benchmarked problem instances.
