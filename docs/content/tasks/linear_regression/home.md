[The task](https://saminulh.github.io/dpstats/linear_regression/) is to privately estimate the regression coefficients from a dataset of sensitive features and outcomes. An algorithm's error is how far its coefficients lie from the ordinary least-squares coefficients, the nonprivate estimate used in practice. It succeeds when that error is within a factor of τ of the least-squares coefficients' own sampling error. [The rankings](https://saminulh.github.io/dpstats/methodology/) order algorithms by τ@50, their median error ratio, lower is better.
