# Outcomes API reference

Algorithms, transformations, budgets, domains, task types and losses signal a
non-release outcome through the types in `dpstats.exceptions`, and
execution records each cell by the one it raises.

See [Privacy budgets and accounting](../tutorials/privacy_budgets_and_accounting.ipynb) for the accounting helpers that
refuse an unrealizable budget family with `InvalidRegime`.

::: dpstats.exceptions
